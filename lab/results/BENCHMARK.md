# memwax lab benchmark results

Generated by `lab/bench/compare.py` from real runs of `lab/bench/run_memwax.py` and `lab/bench/run_amg.py`. Do not edit by hand; re-run `python lab/run_benchmark.py`.

- memwax 0.1.0 (Python 3.13.0, Windows-11-10.0.26200-SP0)
- OWASP Agent Memory Guard 0.4.0 (Python 3.13.0), separate virtual environment
- Corpus: 64 attack samples in 4 categories, 32 benign memory files, 3 clean host templates (sanity check)

A sample counts as *detected* if the tool flags the file. For memwax that means a finding at or above the stated severity. For AMG `scan()` it means `safe == False`; for the AMG adapters it means the write was blocked, quarantined, or redacted.
